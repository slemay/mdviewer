MDViewer Privacy Policy

Overview Support & FAQ GitHub Repository

Effective Date: September 3, 2026

MDViewer ("the Application") is an offline-first Markdown viewer for macOS designed with absolute privacy by default.

1. Zero Data Collection

MDViewer does not collect, transmit, store, track, or share any personal information or telemetry. There are no user accounts, no analytics SDKs, and no tracking cookies.

2. Local Document Processing

All Markdown rendering, mathematical equations (KaTeX), syntax highlighting (Prism), and diagram compilation (Mermaid) occur strictly on your local Mac. Your documents and file paths are never uploaded to any remote server.

3. Network Communications

The Application requires no internet connection to operate. The only external network requests that may occur are when a document you open contains an explicit image link hosted on the web (e.g., status badges or remote screenshots). In such cases, macOS WebKit fetches the image directly. MDViewer does not transmit telemetry or tracking data with these requests.

4. Mac App Store Sandboxing

MDViewer adheres to Apple's App Sandbox security standards. The app operates inside an isolated sandbox container and can only access files you explicitly grant permission to via Finder double-click, drag & drop, or the system file open dialog.

5. Contact & Questions

If you have any questions regarding this Privacy Policy, please contact us via our GitHub repository:
