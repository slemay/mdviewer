How do I open Markdown files?

You can double-click any .md file in Finder, drag & drop files onto the app window or Dock icon, use File > Open... (Cmd + O), or run mdviewer file.md from your terminal.

How does Live Sync work?

MDViewer uses native macOS kernel file events (DispatchSourceFileSystemObject). Whenever you save changes in your favorite editor (such as Neovim, Helix, VS Code, or Sublime), MDViewer updates immediately without flickering while keeping your exact scroll position.

How do I install the command-line tool?

Open MDViewer > Settings... (Cmd + ,), select the Terminal Integration tab, and click Install to ~/.local/bin. You can also copy the terminal alias directly to your shell configuration.

Which Markdown extensions are supported?

MDViewer includes full support for LaTeX mathematics via KaTeX ($...$ and $$...$$), flowcharts and diagrams via Mermaid (```mermaid), Prism syntax highlighting with line numbers and one-click code copy, GitHub callouts ([!NOTE], [!WARNING]), and GFM tables.

How do I export to PDF or HTML?

Choose File > Save as PDF... (Cmd + P) to create a clean, paginated vector PDF. You can also choose Edit > Copy Rendered HTML (Cmd + Shift + C) to copy formatted HTML to your clipboard.
